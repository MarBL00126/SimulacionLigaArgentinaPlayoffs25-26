# Simulador Liga Argentina
Aqui esta un simulador para simular los playoffs y predecir las probabilidades de playoffs y el ascendido a La Liga Nacional 26/27

El Simulador esta en el archivo **SimulacionLigaArgentinaPlayoffs.ipynb** donde se ve detalladamente el procedimiento y al final veremos las probabilidades y el equipo que ascendera a la Liga Nacional del proximo año
